# ✂️🪨📄 Rock‑Paper‑Scissors Mobile Application

A Python‑based mobile application that recreates the classic **Rock, Paper, Scissors** game with a clean interface and smooth user interaction.

## 🎨 Technologies Used
Developed using:
- **CustomTkinter** — for a modern, customizable UI  
- **Pillow (PIL)** — for image handling and rendering  

These tools were chosen to demonstrate strong skills in interface design, game logic implementation, and user‑focused interaction.

## 🕹️ Gameplay Overview
- The player competes against an intelligent bot 🤖  
- Scores are tracked throughout the session 📊  
- A reward system is planned for future updates to enhance engagement and replayability 🎁  

## 🚀 Project Purpose
This project showcases:
- Python GUI development  
- Event‑driven programming  
- Game logic structuring  
- UI/UX considerations in small‑scale applications
